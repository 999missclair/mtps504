    Phase 1 · Investigating & defining

    How does a four-panel joke work?

    Before you build one, pull one apart. Comic artists use panels, gutters and shot types to control exactly where your eye goes and how fast the story feels. Learn the four words, then use them.

    Project overview

    What you're making

    A four-frame cartoon, built from images you find online under a licence you can name. Five phases, six weeks, one joke that has to land in the last box.

    The five phases

    1. 1 Look — how a four-panel joke works
    2. 2 Roll — get your brief
    3. 3 Plan — four frames on paper
    4. 4 Build — the studio
    5. 5 Share — the gallery

    Finished means

    • Four frames, in order.
    • A caption on each frame.
    • An attribution line for every image.
    • Posted to the class gallery.

    The studio

    1. 🖼 Upload won't work? Check the file is a JPG or PNG under 5MB.
    2. 🖐 Drag won't drag? Use the ◀ ▶ buttons — same result.
    3. 💥 Nothing loads? Open the Slides template instead.

    Crediting images

    Title — creator — source — licence. One line per frame. If you can't name the licence, you can't use the image.
